◆ FreqRatio

uint8_t ICS_Params_t::FreqRatio

Used in case of dual MC to synchronize TIM1 and TIM8. It has effect only on the second instanced object and must be equal to the ratio between the two PWM frequencies (higher/lower). Supported values are 1, 2 or 3.

◆ IsHigherFreqTim

uint8_t ICS_Params_t::IsHigherFreqTim

When FreqRatio is greater than 1 this param is used to indicate if this instance is the one with the highest frequency. Allowed values are: HIGHER_FREQ or LOWER_FREQ.

◆ RepetitionCounter

uint8_t ICS_Params_t::RepetitionCounter

Expresses the number of PWM periods to be elapsed before compare registers are updated again. In particular: \( RepetitionCounter\ =\ (2\times PWM\ Periods)\ -\ 1 \)

◆ Tw

uint16_t ICS_Params_t::Tw

Used for switching the context in dual MC. It contains the biggest delay (expressed in counter ticks) between the counter crest and ADC latest trigger. Specific to F4XX.
