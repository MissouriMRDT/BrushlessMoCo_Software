Detailed Description

Profiler component of the Motor Control SDK.

This procedure can be used to identify any PMSM.

Once the profiler complete successfully the motor parameters \(R_s,\ L_s\) and motor flux \(\psi_{mag} \) are provided.
The estimated \(R_s\) and \(L_s\) are then used to define the PI settings ( \(K_p,\ K_i\)) for current controllers.

Enumerator
PROFILER_ERROR_None 

No error detected.

PROFILER_ERROR_DCAC 

Measured motor parameters are out of expected ranges.

PROFILER_ERROR_FluxEstim 

Resulting speed from the flux observer (HSO) and the open loop frequency does not match.

PROFILER_ERROR_NotReady 

Profiling not ready to start, the procedure is not in a suitable state.

◆ _PROFILER_State_e_

enum _PROFILER_State_e_

Profiler States, lists all the possible profiler state machine states.

Enumerator
PROFILER_STATE_Idle 

Profiler Idle state.

PROFILER_STATE_DCandACcheck 

DC and AC measurement step.

PROFILER_STATE_FluxEstim 

Flux estimation step after DCAC step complete whitout error.

PROFILER_STATE_Complete 

Profiler complete state set when procedure is finished.

PROFILER_STATE_Error 

Error occurs when profiler procedure is not ready to start, mainly in two cases:

  • Control Mode is not in Profiling mode
  • or PWM are not in state forced to zero
PROFILER_STATE_DCAC_Error 

Error occurs when DCAC profiler step failed, when measured Rs or Ls are out of expected ranges.

PROFILER_STATE_FluxEstim_Error 

Error occurs when motor fails to spin during profiling.
