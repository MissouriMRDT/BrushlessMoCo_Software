◆ FreqRatio

uint8_t R3_1_Params_t::FreqRatio

Used in case of dual MC to synchronize TIM1 and TIM8.
It has effect only on the second instanced object and must be equal to the ratio between the two PWM frequencies (higher/lower). Supported values are 1, 2 or 3.

◆ IsHigherFreqTim

uint8_t R3_1_Params_t::IsHigherFreqTim

When FreqRatio is greater than 1 this param is used to indicate if this instance is the one with the highest frequency.
Allowed value are: HIGHER_FREQ or LOWER_FREQ.
