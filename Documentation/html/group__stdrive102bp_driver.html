◆ STDRIVE102BP_ClearFault_Cmd()

uint16_t STDRIVE102BP_ClearFault_Cmd ( STDRIVE102BP_Handle_t *  pHandler,
uint8_t  cmd 
)

It sends commands to the STDRIVE102 to clear the different fault conditions.

Parameters
[in]hdlDriver handler.
[in]cmdSelects which is the fault condition to be cleared. This parameter can be one of the following defined commands codes:
  • STDRIVE102BP_CMD_CLEAR_STATUS_L: resets the latched bits in the STDRIVE102 status registers.
  • STDRIVE102BP_CMD_CLEAR_HW_FAULTS: releases the hardware latch of the STDRIVE102 (gate drivers operative).
  • STDRIVE102BP_CMD_CLEAR_ALL: resets the hardware latch and clear the status bits.
  • STDRIVE102BP_CMD_CLEAR_RESET: clear the reset bit in the STATUS2 register.
Return values
uint16_tError code related to SPI communication and the STDRIVE102 state.
