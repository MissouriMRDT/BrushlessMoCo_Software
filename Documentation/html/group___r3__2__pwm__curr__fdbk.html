Detailed Description

3-Shunt, 2 ADCs, PWM & Current Feedback implementation for F30X, F4XX, F7XX, G4XX, H5XX, H7XX and L4XX MCUs

This component is used in applications based on STM32 MCUs, using a three shunt resistors current sensing topology and 2 ADCs peripherals to acquire the current values.

◆ R3_2_SetADCSampPointPolarization()

uint16_t R3_2_SetADCSampPointPolarization ( PWMC_Handle_t *  pHdl)

Configures the ADC for the current sampling during calibration.

It sets the ADC sequence length and channels, and the sampling point via TIMx_Ch4 value and polarity. It then calls the WriteTIMRegisters method. Called R3_2_SetADCSampPointCalibration in F4XX, F7XX and L4XX.

Parameters
pHdlHandler of the current instance of the PWM component.
Return values
uint16_tReturns the value of R3_2_WriteTIMRegisters.
