Current sampling

Prev: Circle limitation ↤| Table of Contents |↦ Next: Current sampling in three-shunt topology using two A/D converters

Introduction to the PMSM FOC drive shows that current sampling plays a crucial role in PMSM field-oriented control. The ST motor control library provides all the components for supporting three-shunt, single-shunt, and ICS topologies. For further details, refer to the following sections:

  • Current sampling in three-shunt topology using two A/D converters
  • Current sampling in three-shunt topology using one A/D converter
  • HSO current and voltage sampling in three-shunt topology
  • Current sampling in single-shunt topology
  • Current sampling in isolated current sensor topology
  • Current sensing and protection using embedded OpAmps and Comparators

The selection of decoding algorithm — to match the topology actually in use — can be performed through correct settings in the ST MC Workbench GUI used to initialize the MC Application during its boot stage.
